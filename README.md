## Ringkasan Materi

### Pertemuan 1 — Pengenalan PHP
Pada pertemuan pertama mempelajari dasar penggunaan PHP, meliputi:
- Struktur penulisan PHP
- Penulisan komentar
- Variabel
- Konstanta
- Penggunaan PHP bersama HTML
- Latihan dasar PHP
📂 [Buka Pertemuan 1](./pertemuan-01/README.md)
---

### Pertemuan 2 — Elemen-Elemen Dasar PHP
Pada pertemuan kedua mempelajari elemen dasar PHP, meliputi:
- Operator aritmatika
- Operator assignment
- Operator pembanding
- Operator logika
- Operator string
- Tipe data
- Implementasi operasi perhitungan
📂 [Buka Pertemuan 2](./pertemuan-02/README.md)
---

### Pertemuan 3 — Struktur Kontrol
Pada pertemuan ketiga mempelajari struktur seleksi untuk menentukan alur program, meliputi:
- Pernyataan `if`
- Pernyataan `if...else`
- Pernyataan `if...elseif...else`
- `switch case`
- Implementasi perhitungan diskon
- Implementasi seleksi berdasarkan kondisi
📂 [Buka Pertemuan 3](./pertemuan-03/README.md)
---

### Pertemuan 4 — Struktur Kontrol Lanjutan
Pada pertemuan keempat mempelajari struktur perulangan, meliputi:
- `for`
- `while`
- `do...while`
- `foreach`
- `continue`
- Perbedaan `break` dan `continue`
- Implementasi tabel perkalian menggunakan looping
📂 [Buka Pertemuan 4](./pertemuan-04/README.md)
---

### Pertemuan 5 — Manipulasi Berkas
Pada pertemuan kelima mempelajari pengolahan berkas menggunakan PHP, meliputi:
- Prinsip pemrosesan berkas
- Mode pembukaan berkas
- `fopen()`
- `fgets()`
- `feof()`
- `fclose()`
- `fputs()`
- `file_exists()`
- Implementasi counter pengunjung
📂 [Buka Pertemuan 5](./pertemuan-05/README.md)
---

### Pertemuan 6 — Array
Pada pertemuan keenam mempelajari dasar penggunaan array dalam PHP, meliputi:

- `foreach`
- Array asosiatif

### Pertemuan 7 — Array Lanjutan
